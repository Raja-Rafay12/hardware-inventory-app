# Hardware Inventory App

This folder contains your hardware shop inventory React application and the source item prices list.

## Folder Structure

- **`HardwareInventoryApp.jsx`**: The React application with all 1,849 unique shop products pre-loaded as seed inventory.
- **`NEW PRICE LIST 2024.xlsx`**: The original Excel sheet containing raw shop item prices.
- **`products.json`**: The compiled clean database of products in JSON format.
- **`extract_products.py`**: The python script used to parse, clean, and categorize the products from the Excel list.
- **`inspect_xlsx.py`**: A helper script to inspect worksheets in the Excel file.
- **`read_xlsx.py`**: A helper script to convert Excel sheets to CSV.
